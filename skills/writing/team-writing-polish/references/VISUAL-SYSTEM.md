# 视觉系统与制作

## 共同语言

默认以科技杂志专题页为目标，另有四种独立风格，选择规则见 [VISUAL-STYLE-CATALOG.md](./VISUAL-STYLE-CATALOG.md)。风格与受众分开确定。用户品牌可覆盖配色；修改后重查对比度。利用标题字形、图像尺度、留白和网格建立视觉辨识度，不模仿媒体标识、刊号或官方署名，尤其不使用 MIT 标识或暗示由其出版。

默认起点如下；这是设计建议，不是从用户图片采样所得的颜色。

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 背景 | `#F6F4EE` | 暖纸色阅读底面 |
| 主文字 | `#202521` | 标题、正文、图形标签 |
| 次要文字 | `#59615B` | 来源、图注及辅助说明，使用时复查背景对比度 |
| 强调 | `#28584A` | 核心判断或图中的关键关系 |
| 分隔 | `#D9DED7` | 非承重的分隔线，不用于小字 |

绿色只承担少量重点，不同时涂满编号、引用、标签、背景和所有箭头。图中有语义作用的边界与连线需要清楚可辨，不能套用低对比度装饰线。原始证据图保留本身配色，通过中性留白和图注融入版面。

共享起点：400 CSS px 画布、26 px 左右边距、16 px 图内间隔；空间标尺为 4/8/12/16/24/32/48/64 px。正文 17 px / 1.65，图注 13 px / 1.5，必要标签至少 14 px，非关键元信息可用 12 px；分节标题约 26 px，主标题约 42 px，具体由风格配置覆盖。解释图线宽 1.5 px、弱分隔 1 px，必要面板圆角 0～4 px。关键条件使用正文尺度，密度设置不得降低字号。

验证 360/400/430 CSS px，并查看分享平台以 360 px 显示时的真实阅读尺度。普通正文、图注与必要标签对比度至少 4.5:1，必要图形边界至少 3:1。采用单列，短指标或简单对照可双列；复杂对照改为纵向。字号数值是起点，实际读图发现过小时必须调整。

PNG 的像素倍率只提高锐度，不增加阅读时的文字大小。以缩放到手机宽度后的效果验收；长内容增加高度或拆分，不通过缩小字体塞满。

## 杂志级编排

制作前用一句话确定本文的视觉主张，例如“用纸桥缺口呈现既有测试与新任务之间未补齐的证据”。它应由内容或原图推导，不是“高级、简约、有质感”等形容词。再确定字体配对、强调色和主图位置，沿全文保持一致。

- **开篇构图。** 标题、导语与主图共同形成一个焦点。优先从原图选择与主张相关的主视觉；没有合适图片时可以使用有依据的信息图或字形构图，不为杂志感强制加封面。不要将标题、标签和多张图等量堆在首屏。
- **字形分工。** 正文用清晰的中文黑体；专题标题可用适合内容的宋体或更有力度的黑体，与正文形成可见差异。全文控制在少量字族与字重，系统回退也要查看实际画面。大字用于判断，小字用于来源，关键条件保持正文尺度。
- **网格与对齐。** 标题、正文、图注共享明确的基准线。桌面可用不对称正文与边注，手机收为单列；不要把复杂双栏压在手机上。以有意的宽窄变化组织主图、正文和证据，而非任意错位。
- **阅读节奏。** 开篇建立主题，正文解释，主图或关键句提供停顿，证据区再展开细节。章节可以采用不同密度，但不要求固定顺序或模板数量。避免每节都重复编号、标题、等高卡片、分隔线的组合。
- **原图与版面的关系。** 给重要原图足够宽度和留白；信息密集的图可以完整保留后加局部放大。周边配色可以呼应原图，不能反过来为适配配色修改证据。生成插画采用具体对象、动作和构图，避免无关科技符号。
- **细节收束。** 检查中文标题断行、孤立标点、图注归属、线条粗细和段间距。不要用虚构刊号、假作者、装饰性数字、重复英文标签或大面积空白冒充编辑设计。

本技能模板展示一种观点驱动方向：宋体专题标题、黑体正文、暖纸色与深绿色、完整宽幅概念图、正文边注和独立证据区。它是可调整的示例，不要求所有题材使用相同主图或章节组合。机制驱动版本须重排骨架，将主机制图置于第一焦点；制作顺序与预览确认见 [VISUAL-EDITING.md](./VISUAL-EDITING.md)。

## 模块由任务决定

| 内容任务 | 可用表达 | 要核对的关系 |
| --- | --- | --- |
| 核心判断 | 大标题、短导语、证据段 | 标题是否比证据更强 |
| 具体情境 | 一个案例或请求路径 | 对象、条件和结果是否能对应 |
| 机制解释 | 数据流、时序、局部架构 | 方向、并发、反馈、边界 |
| 对照证据 | 表格、同口径数据图、前后对照 | 单位、分母、基线、时间、缺失值 |
| 适用条件 | 邻近说明、边界标注、失败分支 | 哪个条件影响哪条结论 |
| 决策选择 | 取舍对照、条件分支、验证路径 | 已知进展与建议动作是否混淆 |

模块可以省略、组合或重复，模板没有固定章数。原文图片默认尽量保留，先调整位置和周边版式；新增候选图若不改善理解，则优先不生成。没有可靠数值时用结构或流程表达，不能用无刻度柱高、虚构趋势或示意百分比制造证据。

需要配图时按 [ILLUSTRATIONS.md](./ILLUSTRATIONS.md) 完成策划、制作和嵌入。封面插画可以建立具体情境，正文配图应就近解释相应机制或证据；不在每段之间机械插图，也不让生成插画承担精确数据或事实证明。

## 自包含 HTML

新风格系统使用 `../assets/templates/editorial.html`、共享 CSS 与五份配置，通过固定脚本生成自包含页面，协议见 [RENDERING-CONTRACT.md](./RENDERING-CONTRACT.md)。原 `../assets/editorial-template.html` 与相邻 `editorial-cover.png` 保留为单篇杂志设计样张，不能当作五风格渲染入口，也不得机械复用纸桥素材到无关主题。

替换示例内容、语言、主题、标题和来源，移除不适用模块。受众仅用于内部取舍，不在标题、眉题、正文或图注突出“给谁看”；眉题可写实际主题，也可以省略。Markdown 维护正文，HTML 保持同一事实与条件；图中增加的信息也回写到 Markdown 的图解或图注。

- 使用语义 HTML，正文是可选择文本，不把整页文字绘进 canvas 或图像。
- CSS、SVG 和必要素材内联；不依赖 CDN、远程字体、跟踪脚本。对外链接仅作引用，加载页面不应发起外部请求。
- 默认使用系统中文字体栈；查看实际字形与字体回退。嵌入字体前检查许可，不能从系统字体目录直接复制并对外分发。
- SVG 提供可辨认的节点、箭头、文字标签及文字说明。确保缩放后标签不小于图注尺度；复杂图拆开，不直接缩小宽图。
- 原始材料含 HTML 时按文本处理或安全转写，不直接执行其中脚本。避免动画、折叠正文和仅 hover 可见的条件，以免导出时丢失内容。
- 图像模型只处理必要插画，不生成大量中文、精确数字、坐标或架构连线。来源证据图不得用生成图替代。

## 本地渲染路径

优先使用本技能固定渲染脚本和环境已有的本地浏览器。浏览器打开最终 `index.html`，设手机视口，等待字体及本地图片加载，再检查布局与导出。默认 400 CSS px × 2.7 倍得到 1080 输出像素；记录实际宽度与倍率。

在 Markdown 与 HTML 中显式区分阅读主线和附录，例如 HTML 使用 `article[data-export="main"]` 与其外的附录区域。按主线区域导出 PNG，不默认将附录、制作说明和导航一起截图；重要限制不能放到导出边界之外。

导出后读回 PNG，确认与最终 HTML 的主线一致。高度超过浏览器、分享渠道能力或实际阅读预算时，按章节输出连续 `part-01.png` 等，保留顺序和必要图注，不在结论与条件之间裁切。即使浏览器能截完整页，也要检查是否应拆成系列图。若工具不能可靠生成整图，就说明只有分段图，不能用空文件或改扩展名冒充 `longform.png`。

脚本覆盖首版支持的图形与版式；超出能力时可使用现有本地工具确定性制作，保留相同来源、版本和验收合同，不宣称脚本已覆盖该能力。缺少工具时交付可用内容并说明未完成的格式，不把临时安装、远程上传或收费服务当作默认步骤。
