# 视觉系统与制作

## 共同语言

默认用米白或浅灰底、近黑正文、一种克制的强调色。用户品牌可覆盖配色；修改后重查对比度。利用标题层级、留白、细分隔和网格分配注意力，不模仿媒体标识、刊号或官方署名，尤其不使用 MIT 标识或暗示由其出版。

移动端起点：390～430 CSS px 视口，正文 16～18 CSS px，主标题 30～40 CSS px，中文行高 1.55～1.75。普通正文、图注与数据标签对比度至少 4.5:1。图注建议不小于 14 CSS px，关键条件使用正文尺度。采用单列，短指标或简单对照可双列；复杂对照改为纵向。

PNG 的像素倍率只提高锐度，不增加阅读时的文字大小。以缩放到手机宽度后的效果验收；长内容增加高度或拆分，不通过缩小字体塞满。

## 模块由任务决定

| 内容任务 | 可用表达 | 要核对的关系 |
| --- | --- | --- |
| 核心判断 | 大标题、短导语、证据段 | 标题是否比证据更强 |
| 具体情境 | 一个案例或请求路径 | 对象、条件和结果是否能对应 |
| 机制解释 | 数据流、时序、局部架构 | 方向、并发、反馈、边界 |
| 对照证据 | 表格、同口径数据图、前后对照 | 单位、分母、基线、时间、缺失值 |
| 适用条件 | 邻近说明、边界标注、失败分支 | 哪个条件影响哪条结论 |
| 决策选择 | 取舍对照、条件分支、验证路径 | 已知进展与建议动作是否混淆 |

模块可以省略、组合或重复，模板没有固定章数。删除图后理解不受影响时，优先删除图。没有可靠数值时用结构或流程表达，不能用无刻度柱高、虚构趋势或示意百分比制造证据。

## 自包含 HTML

复制 `../assets/editorial-template.html` 后替换示例内容、语言、主题、标题和来源；它是可直接打开的排版起点，不是自动转换器。成品中不要残留示例标识或不适用模块。受众仅用于内部取舍，不在标题、眉题、正文或图注突出“给谁看”；眉题可写实际主题，也可以省略。Markdown 维护正文，HTML 保持同一事实与条件；图中增加的信息也回写到 Markdown 的图解或图注。

- 使用语义 HTML，正文是可选择文本，不把整页文字绘进 canvas 或图像。
- CSS、SVG 和必要素材内联；不依赖 CDN、远程字体、跟踪脚本。对外链接仅作引用，加载页面不应发起外部请求。
- 默认使用系统中文字体栈；查看实际字形与字体回退。嵌入字体前检查许可，不能从系统字体目录直接复制并对外分发。
- SVG 提供可辨认的节点、箭头、文字标签及文字说明。确保缩放后标签不小于图注尺度；复杂图拆开，不直接缩小宽图。
- 原始材料含 HTML 时按文本处理或安全转写，不直接执行其中脚本。避免动画、折叠正文和仅 hover 可见的条件，以免导出时丢失内容。
- 图像模型只处理必要插画，不生成大量中文、精确数字、坐标或架构连线。来源证据图不得用生成图替代。

## 本地渲染路径

优先用环境已有的浏览器自动化或截图能力，不强制安装某种框架。浏览器打开最终 `index.html`，设手机视口，等待字体及本地图片加载，再检查布局与导出。可用 2 倍像素倍率导出；记录 CSS 宽度与倍率以便复查。

导出后读回 PNG，确认与最终 HTML 一致。高度超过浏览器或分享渠道能力时，按章节输出连续 `part-01.png` 等，保留顺序和必要图注，不在结论与条件之间裁切。若工具不能可靠生成整图，就说明只有分段图，不能用空文件或改扩展名冒充 `longform.png`。

第一版不提供固定渲染脚本；现有工具足够时直接使用。缺少工具时交付可用内容并说明未完成的格式，不把临时安装、远程上传或收费服务当作默认步骤。
