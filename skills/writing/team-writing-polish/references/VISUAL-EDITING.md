# 视觉编辑：从文案到版面骨架

本阶段位于编辑脚本之后、完整排版和长图导出之前。先让一个判断和一个视觉焦点站出来，再决定其他信息的位置。不要把所有段落依次套入“编号、标题、正文、小图”。

## 主判断与第一焦点

从事实底稿确定一句足以统领文章的判断，同时列出它不能省略的成立条件。第一视觉焦点可为观点标题、主机制图或关键证据图，不要求每篇都有概念封面。首屏通常由主判断、一句必要解释与主视觉组成；来源、图注和重要限定仍须清晰，避免重复导语、引用和标签叠成流水账。

例如“动作完成 ≠ 任务完成”只能在源材料支持这一差异时使用。机器人闭环的节点、传感数据、重试和失败处理也必须有依据，不能因为图好看就补成已具备的能力。

## 两种骨架分别设计

| 阅读任务 | 版面骨架 | 第一视觉焦点 | 补充材料的位置 |
| --- | --- | --- | --- |
| 观点驱动 | 主判断 → 为什么重要 → 价值与代价 → 风险及决策条件 | 一句判断，配支持它的关键对照、证据或情境 | 复杂技术截图可进后续证据区或 HTML 附录，保留原件和引用 |
| 机制驱动 | 主机制图 → 输入/状态/输出 → 验证证据 → 失败边界与取舍 | 贯穿文章的机制、数据流或状态图 | 详细参数、完整日志和非关键截图进 HTML 附录 |

这些是阅读路线，不是必填栏目。来源没有价值测量、失败路径或决策目的时，保留缺口或省略不适用模块。两版共用事实，但主图、重点和空间分配应体现不同任务；不能复制同一 DOM 骨架，只调文字长度。

为每个主要区块简记：读者问题、对应主张、视觉角色、信息密度、原图位置。只保留有用途的区块。允许一个判断占较大面积，也允许一张机制图成为整屏；补充说明退到边注，不能把决定性限制缩成难读小字。

## 图形语言与原图安排

- **证据图**保留真实截图、照片、实验图及其图注与条件。可以改变显示尺寸，或另提供保留上下文的局部放大；不能为统一配色重新生成、滤色或改变证据。
- **解释图**围绕同一视觉语法制作：统一节点含义、字体、线宽、箭头、颜色和状态标识。根据来源可以重绘解释图；保留原件与来源映射，明确新图是编辑解读，不伪装为原始证据。
- 同一篇优先围绕一张主解释图展开，后续局部图复用其节点名称和方向；不为了统一外观强行合并本来不同的流程。照片与解释图通过图注、边距和中性边框融入版面，不要求原图本身风格一致。
- 原文图片默认尽量保留，保留位置可以是主线、局部放大旁或 HTML 附录。清单记录每张原图的去向，避免“没放进长图”变成“从交付中消失”。

## 控制长图范围

先分配阅读主线和支持材料，再决定是单张还是系列。主线必须独立保留结论、必要解释、关键证据和会改变判断的条件；详细参数、完整日志、重复例子及非关键截图可进入 HTML 附录，并提供清楚入口。

`editorial.md` 与 `index.html` 使用对应的主线/附录边界；PNG 对应主线，而非整个网页。附录不默认截图。不能只写“见附录”就从长图删掉决定结论是否成立的条件。

没有通用的最大像素高度。根据实际分享渠道和手机阅读检查判断；需要整体缩小才能读全、章节边界不清或主线已包含多个独立问题时，按自然章节制作系列图。每张图都保留本段结论及条件，不在机制中途或结论与证据之间裁开。

## 先给可审阅预览

先按 [VISUAL-STYLE-CATALOG.md](./VISUAL-STYLE-CATALOG.md) 确定候选。正在选择新风格时，固定受众、文案、事实底稿与素材版本，提供 2～3 个首屏和骨架；只改变构图和视觉表达，不能用文案优劣影响选择。用户已明确选定或沿用风格、要求直接完成时，记录依据并跳过额外确认。

1. 用真实标题、关键句和已取得素材制作 `layout-preview.html`：包括接近最终样式的首屏，以及全篇骨架。骨架区展示各块的阅读任务、视觉角色和相对面积；待制作的图标为待制作，不放伪素材。
2. 有本地渲染能力时导出 `cover-preview.png`，同时检查手机尺度和全篇缩略图。没有渲染能力时提供 HTML 与明确的文字骨架，说明首屏尚未视觉验收。
3. 对两种模式分别展示主判断、第一焦点、主图、证据安排、附录去向和分图计划。成品首屏不标 CEO/CTO；预览说明和目录可以用于区分版本。
4. 新风格选择需请用户确认这一组具体预览，再制作完整长图；明确选定、沿用风格或直接完成的请求不插入额外确认。记录风格 ID/版本、品牌覆盖与内容版本，不代替用户确认尚未作出的选择。
5. 在制作记录保留确认对象及后续修订。改字、对齐和局部间距可继续修正；主判断、骨架、主图职责或重要信息去向改变时，更新相关预览并重新取得对应确认。

预览是中间交付，不是最终长图；默认暂停的是依赖视觉方向的完整制作，不妨碍继续做来源核对、原图整理等已授权工作。用户只要求文字编辑、只问建议或明确要求直接完整制作时，按该范围执行。
