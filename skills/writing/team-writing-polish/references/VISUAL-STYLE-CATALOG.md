# 编辑视觉风格目录

受众和风格是独立维度。CEO/CTO 决定阅读任务、证据深度和内容顺序；风格决定字形、构图、图形语法与节奏。五种名称是编辑设计配置，不是严格艺术史分类，也不表示与媒体或品牌合作。

## 选择与推荐

用户明确指定的风格直接采用；已确认的项目风格沿用。未指定时根据材料推荐 2～3 项，每项说明适合原因与构图差别，默认推荐科技杂志。不要每次强制展示全部五种；用户要求全部对照或工程验收时才完整展示。

| 材料特征 | 优先候选 | 推荐时说明的差别 |
| --- | --- | --- |
| 观点、机制与证据并重 | 科技杂志、瑞士理性主义、现代极简 | 编辑节奏、结构精确性、单一判断集中度 |
| 架构、规范、流程、依赖 | 瑞士理性主义、科技杂志 | 网格与关系图、图文叙事 |
| 可靠且可比较的数据 | 数据新闻、科技杂志、瑞士理性主义 | 图表主导论证、观点与证据交替、同口径对照 |
| 单一判断、少量证据 | 现代极简、科技杂志 | 留白与集中、较丰富的编辑层次 |
| 陌生概念、具体场景 | 插画叙事、科技杂志 | 同一对象状态变化、机制与证据解释 |

没有数据时不把数据新闻作为首选。用户已选择时保留该风格，用有依据的事实对照并说明缺少定量证据，不能生成装饰性柱高。插画叙事不强迫每段配图，原图已经足够时不重复生成。

## 五种实现档案

配色与字体数值以各 `assets/styles/*.json` 为执行来源，风格版本为 `1.0`，独立于整库发行版。共享 CSS 定义不同构图规则，不能只替换色值。

### 科技杂志 `tech-magazine`

- 宋体主标题、黑体正文；42 px 主标题、17 px 正文。暖纸色与深绿色。
- 标题尺度形成第一焦点，主机制图与正文边注、局部证据交替；可用不对称对齐，但保持网格。
- 首屏不叠满标题、长导语、引用和小截图。原文支持时才让机制图成为主视觉。
- 禁止等权编号卡片、通篇绿色、无依据的大数字或媒体标识。
- 去色检查：仍能看到标题尺度、图文密度和编辑停顿的变化。

### 瑞士理性主义 `swiss-rational`

- 无衬线标题与正文；40 px 主标题、17 px 正文。浅底、近黑、克制红色关键路径。
- 强基线、左对齐、明确网格；手机单列，短对照才双列。正交连线与一致节点语法。
- 序号只表达真实顺序；正文不大段居中，不加装饰性渐变或过密三栏。
- 去色检查：结构、依赖与网格对应可辨，不能只是杂志模板换红色。

### 数据新闻 `data-journalism`

- 无衬线与等宽数字特性；36 px 主标题、17 px 正文。白底、蓝色强调，序列色与警告/错误色分开。
- 有限定的判断与主图表先出现，注释、来源、测量条件紧贴证据。图表获得足够面积。
- 柱图通常从零起；直接标注数值、单位、分母、时间窗和已知不确定性。不混淆百分比与百分点。
- 不生成无依据的曲线、预测点、误差带；不用 3D 图表或大量饼图制造信息量。
- 去色检查：论证仍由图表组织，删除主图会损失证据表达。

### 现代极简 `modern-minimal`

- 以无衬线为主；46 px 主标题、18 px 正文。中性底色和少量深蓝重点。
- 一块承担一个主要功能；主判断、对照、证据和边界分开，留白用于分组而非加长页面。
- 首屏允许纯文字；不把每段包进卡片，不把关键限制缩小或删掉。
- 去色检查：焦点集中、结构精简，同时能找到支持判断的证据和边界。

### 插画叙事 `illustrated-narrative`

- 衬线标题与无衬线正文；38 px 主标题、18 px 正文。暖底、棕色与绿色辅助。
- 用同一对象的状态变化解释材料，场景与短说明交替，再落回准确术语。首版确定性场景组件使用同一组几何形状、18 px SVG 字与 1.5 px 线宽。
- 同一篇不混合写实、3D、手绘和卡通；原始证据照片可以保持自身样式，用图注区分身份。
- 类比不是论据，不虚构实验现场；生成图不承载中文参数或精确数据。
- 去色检查：重复对象及状态变化形成解释路径，不是换一张封面插画。

## 两个维度的组合

| 风格 | 观点/决策任务 | 机制/技术任务 |
| --- | --- | --- |
| 科技杂志 | 主判断、价值与选择条件 | 主机制图、证据与技术边界 |
| 瑞士理性主义 | 选项与约束对照 | 层次、依赖、状态转换 |
| 数据新闻 | 少量影响选择的指标 | 测量口径、不确定性、瓶颈 |
| 现代极简 | 一项判断与必要证据 | 聚焦一个技术问题，支持细节进附录 |
| 插画叙事 | 场景与影响路径 | 同一具体案例的机制变化 |

不能由风格自动决定受众，也不能让 CEO 等于删技术、CTO 等于加术语。双模式使用同一事实底稿，各自确定主判断、正文顺序和第一焦点。

## 品牌、密度与可访问性

优先级：安全与事实约束 → 用户当前明确要求 → 已确认品牌 → 选定风格 → 共享默认值。覆盖后的组合重新算对比度，失败时提出可读变体或把品牌色留作非文本装饰；不静默替换品牌色。

`comfortable` 与 `compact` 只改变间距，不缩正文、图注或条件。正文与必要文字至少 4.5:1；必要图形边界至少 3:1。颜色之外还使用直接标签、线型或位置。静态预览选择页使用普通链接、键盘可访问顺序和可见焦点。
