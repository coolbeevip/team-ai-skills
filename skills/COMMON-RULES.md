# Skills 通用规则（被引用）

适用于 `skills/` 下全部 `team-*` 技能。各技能只写差异化规则，不重复本页内容。

## 必须

- 必须优先读取 `team-spec/` 工作空间的上游产物，不绕过阶段边界。
- 必须在入口先确定唯一 `{slug}` 或明确文件路径；无法唯一判断时立即停止并要求用户补充。
- 必须显式声明读写路径，且输出默认写入 `team-spec/{spec|prd|issues}`。
- 必须使用最小可执行输出：短结论 + 必要表格/清单，不默认输出长篇模板。
- 必须在结束前做“完成前检查”，确认路径、slug、上下游可读性。

## 禁止

- 禁止猜测 slug、需求对象、PRD 或 issue。
- 禁止把低频可选流程混入主执行链路。
- 禁止在本仓库沉淀业务项目运行时产物（真实需求、PRD、评审报告、issue）。
- 禁止绕过 `team-spec/prd/{slug}.md` 直接将澄清材料当作工程拆解主输入（除非用户明确要求临时草案）。
