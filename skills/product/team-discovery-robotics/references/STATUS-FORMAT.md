# 项目仪表盘格式

项目仪表盘是项目经理的日常运营视图，记录 `team-spec/active/{slug}/STATUS.md`。每次阶段门转换、重大决策、风险变化或里程碑达成时更新，不得只在阶段门确认时才刷新。

## 1. 模板

## 2. 更新规则

- **阶段门转换时**：更新"整体状态"、"阶段门进度"和"本周决策快照"。
- **收到新证据时**：更新"证据欠账清单"，已收到的移至"已收到"状态。
- **风险变化时**：更新"风险 TOP 5"，新增或升级的风险同步更新"阻塞项清单"。
- **里程碑达成或延期时**：更新"里程碑日历"状态。
- **成本确认时**：更新"成本跟踪"表。
- **干系人沟通后**：追加"干系人沟通记录"。

## 3. RAG 状态定义

| 状态 | 定义 |
| --- | --- |
| 🟢 正常 | 按计划推进，无阻塞项，证据欠账在截止日期内 |
| 🟡 有风险 | 存在 1-2 个一般阻塞项，或证据欠账超过截止日期，或里程碑延期 < 2 周 |
| 🔴 阻塞 | 存在严重阻塞项，或里程碑延期 > 2 周，或关键决策无法确认 |

## 4. 与 AGENTS.md 状态合同的兼容

AGENTS.md 要求 STATUS.md 记录工作区生命周期状态。本仪表盘在满足该要求的基础上扩展，第一节"整体状态"的"生命周期"字段直接使用 AGENTS.md 定义的状态值（`concept-drafting`、`refining`、`spec-ready` 等），其余章节为项目管理扩展内容。
